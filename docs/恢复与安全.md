# 恢复与安全

## 认证与更新

用本机终端的`python -m pavo_website_mcp.login`导入用户自己的Bearer，避免写入命令历史、截图或公开Issue。会话与SQLite都在私有状态目录，仓库不附登录资料。

每次写操作固定账号快照，包括从上传回执读取剧情到提交AI的复合调用。中途导入另一账号只影响后续新操作，进行中的请求仍归开始时的账号；旧凭证被官网撤销时该请求可能失败，不自动改用新账号重投。

更新源码后重新连接MCP，以server_status返回版本为准。更换会话凭证本身不需要重启；工具schema变化则必须重新连接。不要为了修复版本显示而删除状态目录。

## 任务超时与未知提交

1. 保存原operation_id，调用get_operation。
2. 有task_id时查询原生get_task；剧本则查询对应project_id的get_project。
3. SUCCESS只表示请求和回执被保存，仍要核官网任务状态。
4. RUNNING/UNKNOWN禁止换号重投。服务可能已创建任务，HTTP超时不能证明未创建。
5. 官网已成功而本地回执丢失时，保留台账和请求号，先在官网核真实任务。没有自动清除UNKNOWN或强行认领回执的工具。

如进程被强行结束，台账可能停在RUNNING。它仍按未知处理，不把时间过去当成安全重试依据。本服务不承诺服务端未提供的全局exactly-once。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 未登录/401/凭证到期 | 本机终端重新导入官网认证，先验证只读状态，别把Token贴入Issue。 |
| 已安装但工具未出现或参数是旧版 | 重新连接MCP，并读取server_status。核命令指向当前虚拟环境的绝对路径。 |
| 模型不可用或参数不兼容 | 重新读取实时模型列表。保持明确的画幅/分辨率/时长选择，不静默换模型。 |
| 参考数量/类型超限 | 减少或更换参考，或选已授权兼容模型；不能更改role名称绕过数量检查。 |
| 项目只读或演示拒写 | 改用本人可写项目；不修改官方演示。 |
| 剧情源文件缺失或SHA不同 | 还原原文件后使用原回执；确需新内容时重新明确上传。已经生成的项目可直接用真实project_id继续，不重新生成。 |
| 版本或指纹冲突 | 回读当前内容，核用户网页改动后重做本次修改，不能覆盖其他编辑。 |
| 结果回写失败 | 保留提交回执和task_id，恢复回写；不新建生成任务。 |
| 下载中断或回执不完整 | 重试下载。重新下载SHA相同可复用或补建回执；不同的已有文件拒绝覆盖。 |

## 数据与网络边界

- Bearer只发送到固定官网业务API；上传/下载使用独立无凭证客户端。
- 媒体传输固定解析后的公网IP，拒绝本机/内网地址与异常端口，重定向逐跳校验。
- 素材及剧本会按工具职责上传到Pavo。AI文件入口后续发送提取的剧情文本，用户须对素材和发送内容有权操作。
- 本地台账保留操作输入、请求号和回执，可能含剧情与素材地址。0700/0600是访问权限控制，并非数据库加密。
- 公开资料只保留协议说明和模拟测试；生产回执、个人绝对路径、官方演示正文和第三方脚本不纳入公开仓库。

## 已知能力限制

官网剧本接口没有画布式version CAS。指纹能发现检查前的变化，无法消除检查后网页并发修改，操作时避免多端同时编辑。参考预检按节点计数，不能代替媒体实际字节、时长、像素、强制组合规则及生成质量检查。价格为0也不代表长期免费或所有后续阶段免费。
