# 工具参考

当前共43个工具。工具的实际参数以连接后的MCP schema为准；本文说明常用参数、返回值和业务边界。所有需要写入的工具要求稳定的`operation_id`，`dry_run`预览除外，不要用随机操作号绕过UNKNOWN。

## 认证、画布和参考

| 工具 | 主要输入与用途 |
| --- | --- |
| `pavo_server_status` | 无参数；运行版本、脱敏登录状态、API地址。不访问官网。 |
| `pavo_auth_import_authorization` | 用户提供的`authorization`；先只读验证再保存。建议改用本机终端输入以减少会话留存。 |
| `pavo_list_projects` | 无参数；当前账号画布项目列表。 |
| `pavo_create_project` | `title/operation_id`，可选`cover_url`；返回原生项目与画布标识。 |
| `pavo_get_project` | `project_uuid/canvas_uuid`；画布版本、节点和连接。 |
| `pavo_upload_media` | `path/operation_id`；本地绝对路径图片/视频/音频，返回稳定地址、类型与SHA。 |
| `pavo_list_nodes` | `project_uuid/canvas_uuid`；完整节点列表。 |
| `pavo_get_node` | 项目、画布及`node_key`；解码后的节点data。 |
| `pavo_create_node` | 项目、画布、`node_type/operation_id`；可传名称、模型、提示词、params及位置。上传节点需媒体类型和稳定地址。 |
| `pavo_update_node` | 项目、画布、节点及操作号；合并修改名称、提示词、模型、params或data，不整份清空。 |
| `pavo_list_models` | `scene_code=canvas_image/canvas_video/canvas_audio`；实时可用模型、价格和约束。 |
| `pavo_get_model` | `scene_code/model_code`；指定实时模型详情。 |
| `pavo_get_tool_specs` | 可选`code`；不传时返回全部模板，传入时读取指定实时模板。 |
| `pavo_connect_references` | 项目、画布、`target_node_key/references/operation_id`；参考项含source，role为reference或prompt，media_order决定顺序。 |
| `pavo_list_connections` | 项目与画布标识；原生连线列表。 |
| `pavo_validate_canvas` | 项目与画布标识；返回valid/errors/warnings及版本。模型契约缺失的部分不能外推已验证。 |
| `pavo_apply_canvas` | 项目、画布、`operations/operation_id`；默认dry_run，支持create/update/connect，单批1至100项。 |
| `pavo_apply_template` | 项目、画布、`code/inputs/operation_id`；实时guide输入键绑定到现有节点，可指定model/prompt，默认dry_run。 |

首尾帧必须读取实时guide的`extra.node_list`，使用`action_type=input`的真实`node_key`。不能把示例键、模板示例图片或别的模型code当作真实输入。普通media_order只表示输入顺序，不自动证明该参考是首帧或尾帧硬约束。

`params`常用字段是`model/mode/duration/count`及`settings.ratio/resolution/generateAudio`，不同模型并不通用。当前预检按参考节点计数；一个节点含多个产物、媒体字节大小/时长/像素及强制组合规则仍应核官网契约，不把valid当最终生成质量承诺。

## 任务、结果和官网资产

| 工具 | 主要输入与用途 |
| --- | --- |
| `pavo_submit_task` | 项目、画布、`node_key/operation_id`，可选`regenerate`；用户授权费用后提交，返回真实task_id。 |
| `pavo_get_task` | `task_id`；原生found/terminal/succeeded及结果。历史暂缺不等于任务不存在。 |
| `pavo_sync_task_result` | `submission_operation_id/operation_id`；核原提交及节点前置条件后回写，不重新生成。 |
| `pavo_download_task_results` | `task_id/output_dir`；成功任务媒体下载、SHA、逐文件错误。输出目录为绝对路径。 |
| `pavo_save_node_asset` | 项目、画布、`node_key/operation_id`；可选resource_index/name，保存已有节点产物到官网资产。 |
| `pavo_list_assets` | `category=images/videos`及分页；不是剧本角色场景道具列表。 |
| `pavo_list_artifacts` | 项目、画布、category和分页；日期分组的total不能当文件数。 |
| `pavo_get_operation` | `operation_id`；当前账号的本地持久化回执。 |

同一节点重复生成必须明确regenerate且原任务已结束；未解决的UNKNOWN仍拒绝。结果回写或下载有问题，保留生成回执，分别恢复对应步骤。

## 独立AI剧本与三类资料

| 工具 | 主要输入与用途 |
| --- | --- |
| `pavo_script_list_styles` | 无参数；实时风格库。风格ID不是画布模型code。 |
| `pavo_script_list_projects` | page/page_size/is_demo；查询个人剧本或官方只读演示。 |
| `pavo_script_get_project` | `project_id`，可选include_content；状态、大纲、分集、active_tasks与写前指纹。 |
| `pavo_script_get_episode` | `project_id/episode_id`；先核归属再读指定分集。 |
| `pavo_script_create_ai` | `requirements/planned_episode_count/ratio/style/operation_id`；直接AI创作，可能消耗额度。 |
| `pavo_script_import_text` | `raw_text/title/planned_episode_count/ratio/style/operation_id`；剧情原文交给AI分集，0.3起不再按完整剧本paste解析。 |
| `pavo_script_upload_file` | `path/operation_id`；TXT/DOCX上传及检查准备，不自动创建剧本项目。 |
| `pavo_script_import_file` | `upload_operation_id/planned_episode_count/ratio/style/operation_id`；核原文件SHA并提取剧情给AI，不把文件URL当AI参数。 |
| `pavo_script_update_outline` | 项目、`patch/expected_sha256/operation_id`；只改支持字段，保留未改内容。 |
| `pavo_script_update_episodes` | 项目、`episodes/new_episodes/expected_sha256/operation_id`；合并指定改动，发送保留其他已有集的完整列表。 |
| `pavo_script_get_assets` | `project_id`；characters/scenes/props及状态，附_mcp_fingerprints。 |
| `pavo_script_create_asset` | 项目、`asset_type/name/operation_id`，可选description/state_name；手动新建资料及初始状态。 |
| `pavo_script_rename_asset` | 项目、类型、`asset_id/name/expected_sha256/operation_id`；只改实体名称。 |
| `pavo_script_save_asset_state` | 项目、类型、`asset_id/patch/operation_id`；已有状态需state_id与指纹，新增须省略这两项并明确状态名及描述。 |
| `pavo_script_get_storyboard` | 项目及episode_id；真实分集分镜，不触发生成。 |
| `pavo_script_run_stage` | 项目、`stage/operation_id`，按阶段传episode_id/regenerate；只执行明确阶段。 |
| `pavo_script_export` | 项目、`output_dir`，可选format/include_storyboards；本地json/markdown/doc及SHA。doc是Word兼容HTML，不是DOCX。 |

大纲patch支持story_type、target_audience、one_line_story、story_summary、world_setting和character_biographies（name/bio）。分集修改项含episode_id及title/content；新增项含唯一episode_no/title/content。

资产类型取character/scene/prop。状态patch只支持state_name、description、reference_images和episode_nos。参考图使用稳定HTTPS地址，分集绑定只能是本项目现有集号，锁定的绑定不可改。没有图片生成或删除副作用。

stage白名单：confirm_outline、generate_episode、generate_storyboard、extract_assets、finalize_assets、retry_outline、retry_episodes、resume_episodes。finalize_assets独立同步，不随保存自动执行。指定分集/分镜生成必须提供归属正确的episode_id。重试按真实状态执行，不自动循环。
