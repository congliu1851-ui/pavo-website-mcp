# 开发说明与验证边界

## 结构

| 文件 | 职责 |
| --- | --- |
| `client.py` | 固定官网API、Bearer验证、响应信封、脱敏错误 |
| `store.py` | 私有会话、认证上下文、SQLite操作台账、跨进程资源锁及claim |
| `media.py` | 公网URL检查、固定IP连接、独立媒体传输 |
| `canvas.py` | 项目/画布/节点、实时模型、参考图、批量修改及版本冲突 |
| `workflow.py` | 上传、任务、回写、下载与官网媒体资产 |
| `script.py` | 独立playlet剧本、AI分集、阶段、编辑和导出 |
| `script_assets.py` | 三类手动资料、状态、形象主图、角色四视图、指纹及回执核验 |
| `script_media.py` | 原生制作分集、媒体模型、关键帧/视频绑定、选择与任务查询 |
| `script_storyboard.py` | 分镜文字/时长/素材引用编辑及必要拆段结构、指纹、派生值与媒体保护 |
| `server.py` | 中文MCP工具、schema、统一安全错误 |
| `login.py` | 本机不回显的认证入口 |

不添加任意HTTP、命令执行、不受控删除或订阅购买入口。分镜删镜仅限明确整理并保留场景至少一镜，保护其它内容及原段媒体。官网协议不是稳定公共SDK，遇到未识别结构应停止，不能猜字段继续提交。

## 本地开发

```sh
uv sync --frozen --all-groups
uv run --frozen pytest -q
uv run --frozen python -m compileall -q src
uv build
```

测试不需要真实账号；使用临时状态目录、假凭证和模拟HTTP。MCP测试启动真实stdio子进程，核握手、工具发现、参数验证和错误表现。[GitHub Actions模板](../ci/github-actions.yml)配置为在macOS、Linux安装锁定依赖并跑相同测试，不接收官网认证、不生成付费任务。本次凭证缺少workflow权限，自动CI未启用，未声称在GitHub Actions跑通；维护者取得权限后复制模板到.github/workflows/test.yml并提交启用。

项目依赖mcp 2.3.0、httpx 0.28.1，uv.lock固定开发依赖。Python使用>=3.12，因fcntl暂不支持原生Windows。发行包使用明确白名单，不包含本机联调数据或第三方抓取内容。

## 验证分层

1. **离线协议与边界测试**：覆盖账号切换、UNKNOWN防重投、跨进程锁、模型/参考约束、版本冲突、上传无Bearer、下载原子落盘、剧情文件、剧本资产回执和导出。通过这些测试只说明当前客户端逻辑符合夹具及已核契约。
2. **真实MCP进程**：握手、工具schema、只读本地状态和错误调用已核。不能把启动成功当作业务生成成功。
3. **官网只读与非生成联调**：曾读取实时模型/模板/风格和官方只读演示，核剧本JSON导出；专用测试画布的节点、上传、连接、中文提示词与官网资产回读已验证。角色、场景、道具的已上传图片设置为形象主图已通过真实MCP进程调用并回读，既有三视图保持；不等于图片生成接口验证。个人回执和演示正文不公开。
4. **尚未完整生产验收**：收费媒体生成、AI剧情分集和解析、剧本修改/手动资产写入/阶段推进等。不能声称所有官网功能已跑通，更不能承诺人物保真、准确对白或口型。

2026-10-30新增分镜编辑：官网当前前端已核保存、新增片段/镜头、删镜合同，离线覆盖实际写入形状、派生引用、并发指纹、部分失败、超时及媒体保护；新stdio只读已核分镜指纹。首批用户优化文字已真实回读确认；初版引用继承误判已修复，原UNKNOWN经精确前态SHA与当前结果只读核实，保留审计后确认成功，未重投。结构整理仍须另保留逐项生产回执，不把这些模拟测试或工具发现称作生产业务已验证。

测试失败应先缩小到可复现输入再修复。收费写入必须有具体内容、模型参数与费用授权，未知请求不能通过换号“验证”。审查和发布只使用离线测试及只读证据，不为了增加成功数字触发真实生成。

## 协议维护与发布

修改前阅读调用方、工具schema、测试及文档；新增非平凡逻辑先写会失败的测试。新增字段以官网实时响应和直接来源为证，不从第三方模型名字猜能力。公开issue只提供脱敏响应结构、错误码和复现步骤。

发布前执行全套测试、构建、干净克隆安装，检查暂存文件、源码包和wheel没有凭证或个人数据。版本写在pyproject.toml和包__init__.py，修改后同步uv.lock。所有提交说明使用中文；发布功能变化须更新CHANGELOG和工具文档。

错误诊断只输出固定通用类别和HTTP状态/业务码，未知错误保持未分类；不回显服务端可能带入的剧本文字、资源URL或认证。新增回归覆盖凭证、URL及敏感正文不泄漏，重试/UNKNOWN状态机制不因诊断提示而改变。
